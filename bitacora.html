Bitácora de Desarrollo

Registro grupal de toma de decisiones, desafíos técnicos y soluciones implementadas en el TP1.

1. Arquitectura, Estructura y Sistema de Diseño

Acordamos una arquitectura de carpetas limpia y modular (`css/`, `js/`, `img/` y los `.html` en la raíz). Definimos una guía de diseño consistente mediante custom properties en CSS (`:root`), utilizando las familias tipográficas Space Grotesk para títulos y IBM Plex Sans para texto general.

2. Navegación Fluida sin Botón Atrás

Para cumplir con la consigna de accesibilidad, diseñamos un flujo de navegación circular: desde la portada se accede a cada perfil, y cada perfil cuenta con botones para volver a la portada, regresar al perfil anterior o avanzar al siguiente integrante.

3. Desafíos Responsivos en los 3 Breakpoints (400px, 900px, 1200px)

Dificultad: En pantallas de smartphones (menores a 400px), el layout de 2 columnas de los perfiles y el menú horizontal producían desbordes laterales.
Solución: Aplicamos CSS Grid fluido con `grid-template-columns: 1fr` en el breakpoint de 900px y adaptamos la barra de navegación con `flex-direction: column` para 400px.

4. Lógica JavaScript Centralizada y Escalable

Implementamos un único script (`js/perfil.js`) para todas las páginas individuales utilizando selectores basados en atributos personalizados (`data-member`). Esto garantiza cero duplicación de código, evita errores en la consola y otorga a cada integrante una interacción dinámica única.
